# 🐍 Python Learning Lab (30-Day Roadmap)

A structured, day-by-day learning path to build strong Python fundamentals with hands-on practice and backend exposure using Flask & FastAPI.

---

## 🎯 Goal

By the end of this roadmap, you will:

- Understand Python fundamentals deeply
- Write clean and readable code
- Build basic backend APIs
- Be ready for interviews and real-world projects

---

## 🗺️ Learning Roadmap (30 Days)

### 🟢 Week 1: Core Basics

**Day 1 – Hello World & Setup**

- Install Python
- Run first script
  📄 `hello.py`

**Day 2 – Variables**

- Variable declaration
- Naming conventions
  📄 `variables.py`

**Day 3 – Data Types**

- int, float, str, bool
  📄 `data-types.py`

**Day 4 – Type Casting**

- Convert between types
- Common mistakes

**Day 5 – Operators**

- Arithmetic, comparison, logical
  📄 `calc.py`

**Day 6 – Input/Output**

- `input()` and `print()`

**Day 7 – Mini Practice**

- Build small calculator
- Combine everything learned

---

### 🟡 Week 2: Strings & Collections

**Day 8 – Strings Basics**

- Indexing & slicing
  📄 `strings.py`

**Day 9 – String Methods**

- `upper()`, `lower()`, `strip()`, `replace()`

**Day 10 – String Formatting**

- f-strings
- `.format()`

**Day 11 – Lists**

- Create, update, loop

**Day 12 – Tuples & Sets**

- Differences & use cases

**Day 13 – Dictionaries**

- Key-value structure

**Day 14 – Mini Project**

- Contact manager (CLI)

---

### 🔵 Week 3: Logic & Functions

**Day 15 – Conditional Statements**

- `if`, `elif`, `else`

**Day 16 – Loops**

- `for`, `while`, `break`, `continue`

**Day 17 – Functions**

- Define & call functions

**Day 18 – Arguments**

- Default, keyword, return values

**Day 19 – Scope**

- Local vs global
  📄 `global-variables.py`

**Day 20 – Lambda Functions**

- Anonymous functions

**Day 21 – Mini Project**

- Number guessing game

---

### 🟣 Week 4: Real-World Concepts

**Day 22 – File Handling**

- Read/write files

**Day 23 – Error Handling**

- `try`, `except`, `finally`

**Day 24 – Modules & Packages**

- Import custom modules

**Day 25 – Virtual Environment**

- `venv` setup

---

### 🌐 Backend Basics

**Day 26 – Flask API**
📂 `web-api-flask`

- Create simple API
- Routes & JSON response

Run:

```bash
python app.py
```

**Day 27 – FastAPI Intro**
📂 `web-api-fastapi`

- Async APIs
- Auto docs

Run:

```bash
uvicorn main:app --reload
```

**Day 28 – CRUD API**

- Create, Read, Update, Delete

**Day 29 – API Testing**

- Use Postman / Thunder Client

**Day 30 – Final Project**

- Build a simple REST API (e.g., Todo App)

---

## 📂 How to Use This Repo

- Follow day-by-day sequentially
- Run each file and experiment
- Modify examples to learn faster
- Don’t just read → **execute and break things**

---

## 🧪 Example Run

```bash
python strings.py
```

- Practice by modifying examples
- Build small projects weekly
- Focus on concepts, not just syntax
